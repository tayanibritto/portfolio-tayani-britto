# Portfólio Profissional - Tayani Britto

Portfólio profissional desenvolvido para apresentar experiências, projetos, formação e competências técnicas relacionadas ao desenvolvimento Front-End, Back-End Python e automação de processos.

## Sobre o Projeto

Este projeto foi desenvolvido para consolidar conhecimentos em React, Next.js e TypeScript, além de apresentar projetos reais de automação de processos aplicados à área da educação pública.

## Tecnologias

- Next.js 19
- React 19
- TypeScript
- Bootstrap 5
- Jest
- Testing Library
- ESLint
- Prettier
- Husky
- Commitlint
- GitHub Actions
- Vercel
- Resend

## Funcionalidades

- Tema claro e escuro
- Navegação por âncoras
- Páginas 404 e 500 personalizadas
- SEO com Metadata API
- Open Graph
- Sitemap automático
- Robots.txt
- Testes automatizados
- Deploy automatizado

## Passos para clonar e rodar

```bash
git clone https://github.com/tayanibritto/portfolio-tayani-britto.git
```

```bash
cd portfolio-tayani-britto
```

```bash
npm install
```

```bash
npm run dev
```
